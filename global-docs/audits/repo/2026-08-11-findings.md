# Documentation audit — raw findings, 2026-08-11

Companion to `2026-08-11-documentation.html`, which is the **summary**. This file
is the **evidence trail**: the cross-cutting output of all fourteen auditors,
unedited except for grouping.

Read the HTML first. Come here when you are about to change a specific comment
and want to know what the auditor actually saw.

## What this is

A 14-region, read-only audit of every documentation surface in the monorepo —
414 findings, 82 of them P1 (the comment contradicts the implementation).
Regions were partitioned by **file family**, not by course, because the
triplication is partial: `TermuxTerminal.tsx` is byte-identical in all three
courses, `global.css` and `shell.ts` have intermediate == advanced with beginner
diverged, and `progress.ts` and `astro.config.mjs` all differ. An auditor
holding one copy cannot distinguish intentional divergence from drift.

## The four sections below

- **CROSS-FILE CONTRADICTIONS** — 106 places where two sources disagree.
  Auditors were forbidden from resolving these; they are listed for central
  reconciliation. The HTML records the calls made so far. Anything not
  adjudicated there is still open.
- **AUTOMATE CANDIDATES** — invariants currently held by prose alone, each with
  a silent failure mode. Flagged, deliberately not implemented.
- **OUT OF SCOPE** — real code defects found while reading. Reported, not fixed:
  a documentation audit may uncover engineering work without that work becoming
  part of the audit.
- **PATTERNS** — recurring documentation shapes per region.

## Two cautions carried forward

**The `#8b6914` trap.** Two auditors reached opposite conclusions about this hex
and both were wrong. It is live and correct as `--color-warning`, *and* it is
quoted in six places as though it were `--color-brand` (which is `#886713`).
A blanket find-and-replace silently changes the warning colour in all four
projects. Fix only the occurrences that describe *brand*, by hand.

**Fixing comments in dead files may be the wrong remediation.** Advanced ships
`shell.ts`, `TermuxTerminal.tsx`, `LiveSandbox.tsx`, `PracticeSection.astro` and
`BootSplash.astro` that nothing imports. Their comments describe behaviour that
never occurs in that course. Decide whether those files stay before editing
their prose.

Seven findings returned `UNVERIFIED — requires confirmation` rather than
guessing. They are marked as such in the per-region JSON and should not be
promoted to fact without checking.
