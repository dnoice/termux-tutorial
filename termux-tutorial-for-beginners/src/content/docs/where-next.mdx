## What you can actually do

You didn't just read about these — you ran them.

- **Install Termux without breaking it.** You know why the Play Store build is a
  dead end, why every plugin has to come from the same source as the app, and
  what a signature mismatch looks like from the outside (an app that installs
  fine and then silently ignores you).
- **Drive a shell.** `pwd`, `ls`, `cd`, and a fish prompt that suggests, colours
  and completes as you type.
- **Live in the app, not just the shell.** Several sessions at once from the
  left-edge drawer, long-press to copy and paste, scrollback, and the
  notification's **Exit** — plus the knowledge that `Ctrl-C` cancels and has
  never once copied anything.
- **Make and destroy things on purpose.** `mkdir`, `touch`, `cat`, `cp`, `mv`,
  `rm` — plus the `cat >` + **Ctrl-D** (Volume Down + D) trick that turns any
  Android text editor into your terminal editor, and enough respect for `rm -rf`
  to check the path first.
- **Reach your real files.** `termux-setup-storage`, the six symlinks it drops
  in `~/storage`, and the rule that keeps your work alive: **code lives in `~`,
  backups live in `~/storage/shared/`**.
- **Install software.** `pkg update`, `search`, `install`, `list-installed`,
  `uninstall` — a package manager with tens of thousands of packages behind it.
- **Type on a phone without suffering.** A custom extra-keys row, and the volume
  buttons standing in for Ctrl, Esc, Tab and the arrows.

That is a working Linux environment and the literacy to use it. Most people who
install Termux never get here.

## Commands worth meeting next

None of these are hard; they're just the next handful everyone learns. The
practice terminal doesn't run them — that's your device's job now.

| Command | What it's for |
| :------ | :------------ |
| `grep` | Find text inside files |
| `find` | Find files by name, size or age |
| `curl` / `wget` | Fetch things off the internet from the terminal |
| `ssh` | Log into another machine (`pkg install openssh`) |
| `htop` | See what's running and what's eating your battery |
| `man <cmd>` | The manual for any command (`pkg install man`) |

:::tip[Two escape hatches you already have]
In fish, `help` opens its own documentation. And if a tutorial you find online
assumes bash, type `bash` to drop into a bash session for it, then `exit` to
come back to fish. You don't have to choose one forever.
:::

## And when something breaks

It will. That's not a sign you did it wrong — it's Tuesday.

- The [Command Cheatsheet](/reference/cheatsheet/) has every command from this
  course on one page.
- [Troubleshooting](/reference/troubleshooting/) covers the failures that
  actually happen: mismatched signatures, stale package lists, "Permission
  denied", and sessions that die in the background.
- The official [Termux Wiki](https://wiki.termux.com) and
  [r/termux](https://www.reddit.com/r/termux/) are both active and friendly to
  beginners.
