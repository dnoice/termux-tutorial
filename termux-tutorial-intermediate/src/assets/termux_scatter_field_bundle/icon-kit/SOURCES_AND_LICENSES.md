# Icon Kit — Sources and Licenses

Retrieved **2026-08-05**. 69 SVG files, three sources, organized one directory
per source so the license boundary is always visible in the path.

**The one caveat that spans everything here:** an SVG file's *copyright
license* (CC0, MIT, CC BY, GPL) and *trademark rights* in a logo are separate
questions. The licenses below let us copy, modify, and redistribute the
files. Using a brand's mark still needs to be non-confusing, nominative use —
referring to the real project (as an educational course about these systems
does) rather than implying endorsement. That is our lane and we stay in it.

---

## 1. `simple-icons/` — 30 brand marks

- **Source:** Simple Icons project, via jsDelivr CDN
  (`https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`)
- **License:** CC0 1.0 Universal (public domain dedication) for the icon
  files. <https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md>
- **Required attribution:** none (CC0). Simple Icons asks that trademark
  guidelines of each brand be respected; no attribution string is required.
- **Files:** alpinelinux, android, archlinux, debian, docker, fdroid, fedora, freebsd, git, github, gnome, gnu, gnubash, kalilinux, kde, linux, linuxmint, manjaro, mysql, neovim, opensourceinitiative, opensuse, postgresql, python, raspberrypi, redhat, sqlite, tmux, ubuntu, vim

## 3. `wikimedia/` — 3 canonical figures

### `Tux.svg`
- **Source:** Wikimedia Commons -
  <https://commons.wikimedia.org/wiki/File:Tux.svg>
- **Origin:** Larry Ewing's original Tux (1996), SVG tracing by Garrett LeSage.
- **License / required acknowledgment (Ewing's own wording):** "Permission to
  use and/or modify this image is granted provided you acknowledge
  lewing@isc.tamu.edu and The GIMP."
- **Our acknowledgment:** Tux by Larry Ewing (lewing@isc.tamu.edu), created
  with The GIMP; SVG by Garrett LeSage.

### `Android_robot.svg`
- **Source:** Wikimedia Commons -
  <https://commons.wikimedia.org/wiki/File:Android_robot.svg>
- **License:** Creative Commons Attribution 3.0 (per Google's brand terms).
- **Required attribution (Google's specified wording):** "The Android robot
  is reproduced or modified from work created and shared by Google and used
  according to terms described in the Creative Commons 3.0 Attribution
  License."

### `Termux.svg`
- **Source:** Wikimedia Commons -
  <https://commons.wikimedia.org/wiki/File:Termux.svg> (retrieved via
  Special:FilePath). The mark originates from the termux/termux-app
  repository.
- **License:** GPLv3-only (the termux-app repository license, as recorded on
  the Commons file page). Note this is the strictest license in the kit: a
  *derivative of this file* should carry GPLv3 or lean on nominative use
  (displaying the mark to refer to Termux itself). Flagging now so it is a
  conscious choice at remix time, not a surprise.

## What happens next

Dennis remixes selections from this kit in Inkscape (strip fills, outline to
match the digiSpace stroke style, recompose). Once the final selection
exists, we write the comprehensive attribution block together - per mark,
with the exact strings above - and embed it in the ✒ headers of the
deliverables that use them, per the digiSpace docstring standard.
