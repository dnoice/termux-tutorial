This is your personal dashboard. Set a display name and avatar, and check off
lessons as you finish them.

:::note[Everything here is local, and separate from course one]
Your profile and progress live in **this browser's local storage** — there's no
account and nothing is sent anywhere. This course keeps its own store, so
finishing the beginner course does not tick anything off here, and an exported
progress file from that course will not import into this one.
:::
