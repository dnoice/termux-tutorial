sessions, scripts, and a shell you are comfortable in are all treated as known.

:::caution[This is the course that can actually cost you something]
Everything before this was reversible in seconds. Not here.

**Disk.** A Debian rootfs is **1.5–3 GB** before you install anything into it.
A desktop takes more. Check your free space before you start, not after.

**Battery and heat.** PRoot traces every system call, so everything inside the
container runs slower and warmer than the same command outside it. A long build
on a phone is a genuinely hot phone.

**Time.** The desktop lessons have more moving parts than anything in the
series, and a black screen has about six possible causes. Budget accordingly.

None of it needs root, an unlocked bootloader, or a custom ROM. All of it is
undoable — `proot-distro remove` takes the container back off the disk.
:::

## No practice terminal in this course

The earlier courses put a simulator on nearly every page. This one does not, and
the reason is worth stating plainly rather than hiding.

The practice terminal is a hand-written interpreter over an in-memory
filesystem. It cannot install a Debian rootfs, it cannot open an X11 socket, and
it cannot talk to a GPU. A terminal that answered `proot-distro login debian`
with anything at all would be lying about the one thing this course is
teaching — and a lesson you can fake your way through is a lesson you have not
learned.

So this course needs your actual device. Every command here is one you run for
real, and every failure is one you will actually have to read.
