Step 1: First Launch & Keeping Things Updated

Let's get Termux open and do the essential first steps.

  1. Launch Termux: Tap the app icon. You'll see a black screen with text. This is the terminal!
  2. The Command Prompt: That blinking cursor after the $ sign is where you type commands. Think of it as asking Termux to do something. Your starting place is called the "home directory," represented by ~.
  3. Keep Your Tools Updated: Just like apps on your phone need updates for security and new features, Termux needs its tools updated too. This is very important! Run this command now by typing it exactly and pressing Enter: 
    pkg update && pkg upgrade -y

    Let's break that down:

    • pkg: This is Termux's "package manager" – think of it like an app store for command-line tools.
    • update: This checks the list of available software for any new versions.
    • &&: This symbol means "if the first command was successful, then run the next command."
    • upgrade: This downloads and installs the newer versions of any tools you already have.
    • -y: This automatically answers "yes" to any questions Termux might ask during the upgrade, making it faster.

    This might take a minute or two. If it asks about configuration files during the process, it's usually safe to just press Enter to accept the default option (or type 'N' and then Enter). Keeping the defaults is fine for now.

    Great! Your Termux is now up-to-date and ready.

Step 1.5: A Friendlier Command Line (Fish Shell)

The default way you interact with Termux is called "Bash." It works, but there's a much more beginner-friendly option called "Fish" that we highly recommend installing.

Why use Fish? It helps you out!

  • Auto-Suggestions: As you start typing a command you've used before, Fish suggests the rest in gray text. Just press the Right Arrow key () or Ctrl+F to accept it! Saves a lot of typing.
  • Easier to Read: Fish often uses colors to make different parts of commands or file names stand out.
  • Smart Tab Completion: Pressing the Tab key can automatically finish commands, file names, or options. If there are multiple choices, it might even show you a helpful list.
  • Nicer Prompt: The information shown before the blinking cursor (the prompt) is often clearer in Fish.

Let's install and switch to Fish:

  1. Install Fish using `pkg`: 
    pkg install fish
    (Press y and Enter if it asks for confirmation).
  2. Set Fish as Default: Tell Termux you want to use Fish every time you open the app. The command `chsh` means "change shell." 
    chsh -s fish
  3. Reload Termux: Close the Termux app completely (remove it from your phone's recent apps list) and then open it again.

Your prompt should look different now (maybe ending in > instead of $). Try typing ls and notice the colors. This is Fish helping you out!

Excellent! You've upgraded your command-line experience.

(The rest of this guide assumes you're using Fish, but most basic commands work similarly in Bash too).

Step 2: Finding Your Way Around (Navigation)

Like navigating folders on a computer, you need commands to see where you are and move around in Termux.

  • Where Am I? (`pwd`): This command stands for "Print Working Directory." It tells you the exact folder (or "directory") you are currently inside. 
    pwd
  • What's Here? (`ls`): This command "lists" the files and sub-folders within your current directory. Fish might show folders, files, and other types in different colors. 
    ls
    Helpful variations: ls -l shows more details (like size, date). ls -a shows hidden files (names starting with a dot .).
  • Move Somewhere Else (`cd`): This command means "Change Directory." You use it to move into different folders.
    • cd ~ (or just cd): Takes you back to your "home" directory (your starting place).
    • cd ..: Moves you "up" one level to the folder containing your current folder (the "parent" directory).
    • cd <foldername>: Moves you into the specified sub-folder. (Example: cd projects would move you into a folder named "projects" if it exists here). Remember Fish's Tab completion – type cd pro and hit Tab!

Practice moving around! Use pwd to check where you are, ls to see what's there, and cd to navigate.

Step 3: Making Folders & Files

Let's create your own space to keep things organized.

  1. Make a Folder (`mkdir`): This command "makes a directory" (a folder). Let's create one for projects. 
    mkdir projects
    (Use ls after running it to see your new "projects" folder).
  2. Move Into It (`cd`): Now, let's navigate into the folder you just created. 
    cd projects
    (Notice how your prompt might change to show you're inside "projects").
  3. Create an Empty File (`touch`): This command creates a blank file with the name you give it. 
    touch notes.txt
    (Use ls again to see "notes.txt" inside your "projects" folder).
  4. Go Back Home (`cd`): Let's return to your main home directory. 
    cd ~

You've successfully created a folder and a file using commands!

Step 4: Getting New Tools (Packages)

Termux comes with basic commands, but you can install many more tools (called "packages") using the pkg command we used earlier.

  1. Search for Tools (`pkg search`): Want to know if a specific tool is available? Use search. 
    pkg search network
    (This would list packages related to networking).
  2. Install Tools (`pkg install`): To add new tools, use install. Let's get two useful ones:
    • termux-api: A set of commands allowing Termux to interact with Android features (like battery status, clipboard, notifications).
    • nano: A simple text editor that runs inside the terminal. It's good to know, but we'll see an easier way to edit files next.
    pkg install termux-api nano
    (Confirm with y and Enter if asked).
  3. Remove Tools (`pkg uninstall`): If you install something you don't need later, you can remove it. 
    # Example: pkg uninstall some-tool-name

Now you know how to find, install, and remove extra command-line tools in Termux!

Step 5: Editing Text (The Easy Way)

While you can edit files directly in the terminal using tools like `nano` (which we just installed), it can be tricky on a small phone screen. Here's a much more comfortable method using a graphical app.

  1. Get a Text Editor App: Install a good, free text editor app from the Google Play Store. **"QuickEdit Text Editor"** is an excellent choice for this – it's simple and works well with code/text.
  2. Open File from Termux (`open`): Termux has a handy `open` command (you might need `termux-api` installed for it to work best) that tries to open a file using a suitable Android app. Let's try opening the `notes.txt` file we created earlier. First, make sure you're in the right folder: 
    cd ~/projects  # Go to your projects folder
open notes.txt
  3. Choose Your Editor: Android should pop up a menu asking which app to use. Select **QuickEdit** (or the editor you installed).
  4. Understand the Limitation (Android Security): The file will open in QuickEdit. However, Android's security often prevents apps like QuickEdit from directly saving changes back into Termux's private folders. The file might open as "read-only," or saving might create a copy elsewhere. This is normal Android behavior!
  5. The Workaround (Copy & Paste Method): This might seem unusual at first, but it's often faster than fighting with terminal editors on mobile. Follow these steps carefully:
    1. Edit your `notes.txt` file in the QuickEdit app. Add some text.
    2. When finished editing, **Select All** the text within QuickEdit (usually via its Menu button or by long-pressing).
    3. **Copy** the selected text to your phone's clipboard (again, usually via QuickEdit's menu or toolbar).
    4. Switch back to the Termux app (make sure you're still in the `~/projects` directory).
    5. **Crucial Command:** Type the following command exactly. The `cat` command usually displays file content, but `cat > filename` tells it to take whatever you type (or paste) next and *overwrite* the file `filename` with that content. 
      cat > notes.txt
      (Press Enter. Termux will just wait with a blank line.)
    6. **Paste** the text you copied from QuickEdit into Termux (usually by long-pressing on the terminal screen and choosing "Paste"). You should see your text appear.
    7. **The Final, Vital Step:** Press the `Ctrl` key (often Volume Down) and the `D` key simultaneously (`Ctrl + D`). This tells `cat` you're finished providing input, and it saves the pasted content to `notes.txt`. **If you forget Ctrl+D, the file won't save correctly!**
  6. Verify Your Changes (`cat`): To check if your edits were saved, use `cat` *without* the `>`. This command simply displays the file's content in the terminal. 
    cat notes.txt
    You should see the text you edited in QuickEdit!

Practice Makes Perfect: This copy/paste/cat >/Ctrl+D technique is key for easy file editing in Termux using familiar graphical apps. Try it a few times!

Step 6: Talking to Android (Termux API)

Remember installing `termux-api`? That package gives you special commands (mostly starting with `termux-`) that let your Termux terminal interact with Android features.

Permissions Required: The first time you use many of these commands, Android will ask for permission via the "Termux:API" app (a small companion app installed with the package). You generally need to **Allow** these permissions for the commands to work.

Here are a few examples to try:

  • Show a Quick Message (`termux-toast`): Displays a small pop-up notification on screen. 
    termux-toast "Hello from Termux!"
  • Check Battery Status (`termux-battery-status`): Shows information about your phone's battery. 
    termux-battery-status
  • Use the Clipboard (`termux-clipboard-set`/`get`): Copy text *to* the Android clipboard or get text *from* it. 
    termux-clipboard-set "Text set via Termux"
# Now go copy something else normally on your phone...
termux-clipboard-get # This will display what's now on the clipboard
  • Show a Dialog Box (`termux-dialog`): Make Android show different kinds of dialog boxes. 
    termux-dialog confirm -i "Is this guide helpful?" -t "Feedback"
  • Vibrate the Phone (`termux-vibrate`): Makes the phone vibrate. 
    termux-vibrate -d 500 # Vibrate for 500 milliseconds

Tip: Type termux- and then press the Tab key twice quickly. Fish might show you a list of all available Termux API commands! You can get help on any command by adding --help after it (e.g., termux-toast --help).

Step 7: Accessing Your Phone's Storage

By default, Termux operates in its own private storage area (a "sandbox") for security. To access files in your phone's main storage (like Downloads or Pictures), you need to grant permission.

  1. Run the Setup Command: 
    termux-setup-storage
  2. Grant Permission: Android will pop up asking for permission to access files. You need to **Allow** this.
  3. Find the Access Point: Go back to your home directory (cd ~) and list the contents (ls). You should now see a new folder named storage. This is your gateway!
  4. Explore Your Storage: Move into the gateway folder: cd storage. Now run ls again. You'll see several links:
    • dcim: Your camera photos folder.
    • downloads: Your phone's main Downloads folder.
    • movies, music, pictures: Standard media folders.
    • shared: This usually links to the main root of your phone's internal shared storage.

Now you can use commands like cd downloads to enter these folders. Inside, you can use commands like ls (list), cp (copy files), mv (move or rename files), and rm (remove files).

Use `rm` with Extreme Caution! Deleting files with `rm` from the command line is permanent. There is NO recycle bin or undo! Double-check before deleting anything important.

Example: Copy your notes file to your phone's Downloads folder:

# Make sure you're in your home directory first: cd ~
cp projects/notes.txt storage/downloads/
(You should now be able to find `notes.txt` in the Downloads folder using your phone's regular file manager app.)

Step 8: Running Simple Scripts

Instead of typing commands one by one, you can save a list of commands in a file and run them all at once. This is called a "script." It's great for automating repetitive tasks.

  1. Go Home: cd ~
  2. Create a Script File: Use the editing method from Step 5 (or `nano` if you prefer) to create a new file. Let's call it hello.fish (the .fish ending helps indicate it's a Fish script). 
    # Use GUI Hack (Step 5) or nano
touch hello.fish
# open hello.fish # then edit, copy, paste, cat > hello.fish, Ctrl+D
# OR: nano hello.fish
  3. Write Script Commands: Inside the file, type the commands you want to run, one per line. The very first line is special: 
    #!/data/data/com.termux/files/usr/bin/fish

# Lines starting with # are comments (ignored when run)
echo "--- Running my first script! ---"
echo "Hello, Danny!"
echo "The current time is:"
date # This command prints the date and time
termux-toast "Script finished!"
echo "--------------------------------"
    The `#!/.../fish` line (called a "shebang") tells Termux to use the Fish program to run the commands in this file. `echo` simply prints text to the screen.
  4. Save the File: Use the `cat > hello.fish` method from Step 5, or press `Ctrl+O`, Enter, `Ctrl+X` if using `nano`.
  5. Make it Executable (`chmod`): You need to give the file permission to be run as a program. `chmod +x` adds execute permission. 
    chmod +x hello.fish
  6. Run the Script: To run a script in your current directory, type `./` followed by the script's filename. 
    ./hello.fish

You should see the output from your script! You've just automated a sequence of commands.

Helpful Tips & Shortcuts

These will make using Termux (especially with Fish) much easier:

  • Auto-Suggestions: Start typing a command; if you see gray text suggesting the rest, hit Right Arrow () or Ctrl+F to complete it.
  • Tab Completion: Press Tab constantly! After typing part of a command, filename, or folder name, hit Tab. It will try to complete it or show you options.
  • Command History (Up Arrow ): Press the Up Arrow key to cycle through commands you've previously typed. Start typing first to filter the history.
  • Volume Keys as Modifiers: Often, Volume Down acts like `Ctrl`, and Volume Up acts like `Alt`. Useful for shortcuts!
  • Stop a Command (`Ctrl + C`): If a command is running too long or you made a mistake, press `Ctrl+C` to try and stop it.
  • End Input / Logout (`Ctrl + D`): Used to signal the end when typing input (like for the `cat >` trick). Also often used to close the Termux session.
  • Clear the Screen (`Ctrl + L`): Cleans up a cluttered terminal screen.
  • Repeat Last Argument (`Alt + .`): Need to use the last filename or option from your previous command? Press `Alt+.` (Volume Up + Period) to insert it.
  • Editing Workaround (Step 5): Remember the GUI Edit -> Select All -> Copy -> `cat > file` -> Paste -> `Ctrl+D` flow for easy editing.
  • Get Help (`help`): Type help in Fish for its built-in help, or `command --help` for help on a specific command.
  • Exit Termux (`exit`): Type exit and press Enter (or use `Ctrl+D`) to close the current session.

Level Up: Where to Go Next

You've learned the fundamentals! The world of the command line is vast. Here are some ideas for what to explore next:

  • Customize Fish: Run fish_config in Termux to easily change colors and the look of your prompt.
  • Learn More Commands: Look up commands like grep (search text in files), find (locate files), curl or wget (download files from the internet).
  • Programming:** Install programming languages like Python (pkg install python), Node.js, etc., and code directly in Termux.
  • Version Control (`git`): Use pkg install git to manage code projects or download code from sites like GitHub.
  • Connect Remotely (`ssh`): Use pkg install openssh to securely connect to other computers or servers.
  • Read Documentation: Explore the official Termux Wiki and Fish shell documentation online for more details and ideas.
  • Practice Scripting: Try automating simple tasks you do often!

Don't be afraid to experiment (carefully!). The best way to learn is by trying things out. Have fun exploring what you can do with Termux!

Termux: Command the code. Control the system. Own your device.
